# Day 20（12/20 日）100年前の街を歩く

- **アプリ名（フォルダ名）**：`old-map-walk`
- **ジャンル**：歴史
- **完成形**：スマホ向けWebアプリ（PWA）
- **組み合わせるデータ**：位置合わせ済みの古地図 × OpenStreetMap × Wikipedia
- **AI・技術の見どころ**：地図の重ね合わせ＋語り

## 作るもの

今いる場所に100年前の地図を重ね、スライダーで今と昔を行き来しながら、「昔ここには何があったか」をAIが語る

## 使い道

旅先や自分の街の歴史を知る。地図の重ね合わせの実践例

## 確かめ方（評価）

今も残っている建物や道が、古地図と今の地図で何メートルずれているかを測る。AIの解説はWikipediaの記述と照合する

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

位置合わせ済みでパブリックドメインの古地図（ニューヨーク公共図書館など）がある都市を1つ選ぶ
