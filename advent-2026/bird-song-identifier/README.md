# Day 12（12/12 土）鳥の声を聞き分けるAI

- **アプリ名（フォルダ名）**：`bird-song-identifier`
- **ジャンル**：生き物
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：xeno-canto × GBIF
- **AI・技術の見どころ**：音声分類

## 作るもの

録音を渡すと鳥の種類を推定し、録音した場所と季節に観察記録がある種だけに絞り込んで答える

## 使い道

音声分類と、別のデータによる絞り込みを組み合わせる設計の例

## 確かめ方（評価）

学習に使っていない録音で、絞り込みありとなしの正解率を比べる

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

分類は公開済みの鳥の声のモデル（BirdNETなど。非商用ライセンス）を使い、自分では学習しない。xeno-cantoは録音ごとにライセンスが違うので確認する

## 必要な環境変数

- `XENO_CANTO_API_KEY`
