## 📱 アプリ一覧

### 1. [論文サーベイの自動化](paper-survey/)（12/1）
- **説明**: テーマを入れると、重要論文、無料で読めるリンク、日本語の要約をまとめたサーベイを出す
- **データ**: OpenAlex × arXiv × Unpaywall
- **技術**: RAG・要約
- **特徴**: 論文の選び方（関連度＋1年あたり引用数＋新しさ）はコードで計算し、AIは抄録だけを根拠に解説を書く。根拠の番号と数字は自動で照合する。既存サーベイ5本の参考文献を正解にした評価で、上位20本の適合率50%（関連度順のみ38%、引用数順のみ40%）
- **デモ**: https://advent26-paper-survey.vercel.app （1日10回まで）
- **記事**: （公開後に記入）

### 2. [依存ライブラリと脆弱性の優先度判定](dependency-risk-radar/)（12/2）
- **説明**: package-lock.json / requirements.txt を渡すと、脆弱性を「今日対応すべき順」に並べ、理由、パッケージごとの対応、放置された依存の乗り換え先を出す CLI と GitHub Action
- **データ**: OSV × deps.dev × CISA KEV × EPSS
- **技術**: エージェント・判断の説明
- **特徴**: 順位はコードが KEV（悪用確認済み）と EPSS（悪用される確率）で決め、AI は説明と乗り換え先の調査だけ。AI の提案はコードでも実在を確認。時点を戻した評価で、その後悪用された脆弱性の順位の中央値が、深刻度順の1,931位に対して140位
- **デモ**: GitHub Action（`uses: zzzzico12/claude/advent-2026/dependency-risk-radar@main`）。例のレポートは [examples/](dependency-risk-radar/examples/)
- **記事**: （公開後に記入）

### 3. [CO2の少ないクラウドリージョン](green-region-finder/)（12/3）
- **説明**: 利用者の場所と要件（遅延の条件）を入れると、電力の CO2 が少ないクラウドのリージョン（Google Cloud・AWS・Azure）を提案する。料金は扱わない
- **データ**: Ember × リージョン所在地 × Google Cloudの公開カーボンデータ × Azure のリージョン間の実測遅延
- **技術**: 推薦
- **特徴**: CO2 を公開していない AWS・Azure も Ember から推定。推定は Google の公式値と比べて順位の相関 0.89。遅延は Azure の実測値で補正（誤差の中央値 18ms → 13ms）。例：東京から Web アプリなら CO2 −80%
- **デモ**: https://advent26-green-region-finder.vercel.app （AI の説明は1日50回まで）
- **記事**: （公開後に記入）

### 4. [名画のエディタ配色](masterpiece-vscode-theme/)（12/4）
- **説明**: パブリックドメインの名画17点の色から作った VS Code のテーマの拡張機能。文字の読みやすさ（WCAG AA）を全テーマで保証し、天気や時間帯で絵が切り替わる
- **データ**: シカゴ美術館 × Open-Meteo（メトロポリタン美術館は画像を取得できず不使用）
- **技術**: 画像からの配色抽出、VS Code拡張
- **特徴**: 色は k-means で取り出し、どこに使うかは AI が絵を見て決め、読みやすさはコードが保証（272組すべて AA）。AI の割り当ては機械的な割り当てより絵の色を残せた（調整量 ΔE 8.6 対 11.5）
- **デモ**: `.vsix` を作ってインストール（[masterpiece-vscode-theme/](masterpiece-vscode-theme/) の「使い方」）
- **記事**: （公開後に記入）

### 5. [衛星画像で森の変化を検知](forest-change-detector/)（12/5）
- **説明**: 地球全体で2001〜2025年に森が減った場所を年ごとに再生する地図。地域（6大陸＋ロシア）ごとの減少面積と火災の割合を示し、大きく減った年に何があったかを AI が出典つきで説明する
- **データ**: Global Forest Watch（森林減少の地図・国ごとの数字・原因・火災）× Natural Earth × ウェブ検索（すべてキー不要）
- **技術**: 植生指数＋画像の説明（ロンドニア州の分析）、地図タイルの画素の読み取り、出典つきの説明と数字の照合
- **特徴**: 25年で世界の森 5億4,281万 ha が減った。説明14件すべてに出典、文中の数字は集計か出典の文と自動照合（12/14 一致）。当初はロンドニア州の衛星画像の分析（NDVI、再現率34%）として作り、地球全体に作り直した
- **デモ**: https://advent26-forest-change-detector.vercel.app （AI は事前に1回だけ呼ぶので、回数の上限なし）

### 6. [人工衛星は今どこ？](satellite-tracker-3d/)（12/6）
- **説明**: 3Dの地球儀に、今動いている人工衛星 16,904機をリアルタイムで表示する。種類（Starlink・測位・気象・地球観測など）・軌道・国で絞り込み、クリックすると「どこの国の、何のための衛星か」をAIが解説する
- **データ**: CelesTrak（軌道要素・衛星カタログ）× UCS Satellite Database（2023年5月版）× Natural Earth II（地図）。評価に NASA の ISS 軌道データ
- **技術**: SGP4 の軌道計算（Web Worker）＋補間、CesiumJS（ion なし）で1万7千点の描画、事実を渡した解説と数字の照合
- **特徴**: CelesTrak の取得はサーバーで2時間に1回だけ。ISS の位置は NASA のデータと比べて 1.4〜3.5 km のずれ。全機の計算は1回 9.8 ms。共通部品 `packages/orbit`・`packages/globe` を作った
- **デモ**: （公開後に記入。AI の解説は1日10回まで）
- **記事**: （公開後に記入）

## はじめかた

1. `.env.example` を `.env` にコピーして、[docs/setup.md](docs/setup.md) のキーを入れる
2. VS Codeで `advent-2026/` フォルダを開き、Claudeに「`CLAUDE.md` と `docs/plan.md` を読んで、`docs/schedule.md` の11月の作業から始めて」と伝える
3. GitHubにpushしたら、`scripts/create_issues.sh` で25本分のIssue（ラベル `advent-2026`）を作る
4. デプロイは Vercel。アプリごとにプロジェクトを作り、Root Directory を `advent-2026/<アプリ名>` にする（[docs/decisions.md](docs/decisions.md)）
