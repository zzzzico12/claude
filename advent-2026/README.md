# AI×世界のオープンデータ アドベントカレンダー2026

Qiitaアドベントカレンダーで、12月1日〜25日に毎日1本、世界のオープンデータを組み合わせてClaudeと作るAIアプリのコレクションです。[zzzzico12/claude](../) リポジトリの `advent-2026/` に置いています（去年までのアプリはリポジトリのルートの `apps/` にあります）。

- 企画書：[docs/plan.md](docs/plan.md)
- スケジュール：[docs/schedule.md](docs/schedule.md)
- アカウントとAPIキー：[docs/setup.md](docs/setup.md)
- 決めること：[docs/decisions.md](docs/decisions.md)
- Claudeへの共通ルール：[CLAUDE.md](CLAUDE.md)

## 📱 アプリ一覧

### 1. [論文サーベイの自動化](paper-survey/)（12/1）
- **説明**: テーマを入れると、重要論文、無料で読めるリンク、日本語の要約をまとめたサーベイを出す
- **データ**: OpenAlex × arXiv × Unpaywall
- **技術**: RAG・要約
- **特徴**: 論文の選び方（関連度＋1年あたり引用数＋新しさ）はコードで計算し、AIは抄録だけを根拠に解説を書く。根拠の番号と数字は自動で照合する。既存サーベイ5本の参考文献を正解にした評価で、上位20本の適合率50%（関連度順のみ38%、引用数順のみ40%）
- **デモ**: https://advent26-paper-survey.vercel.app （1日10回まで）

## はじめかた

1. `.env.example` を `.env` にコピーして、[docs/setup.md](docs/setup.md) のキーを入れる
2. VS Codeで `advent-2026/` フォルダを開き、Claudeに「`CLAUDE.md` と `docs/plan.md` を読んで、`docs/schedule.md` の11月の作業から始めて」と伝える
3. GitHubにpushしたら、`scripts/create_issues.sh` で25本分のIssue（ラベル `advent-2026`）を作る
4. デプロイは Vercel。アプリごとにプロジェクトを作り、Root Directory を `advent-2026/<アプリ名>` にする（[docs/decisions.md](docs/decisions.md)）
