# Day 24（12/24 木）AIがF1を実況する

- **アプリ名（フォルダ名）**：`f1-ai-commentary`
- **ジャンル**：F1
- **完成形**：Webアプリ
- **組み合わせるデータ**：OpenF1の位置・タイム差・レースコントロール
- **AI・技術の見どころ**：実況の生成＋音声合成

## 作るもの

過去のレースを全車の位置で再生しながら、順位の入れ替わり、ピットイン、タイム差、レースコントロールの指示から、日本語の実況を生成して音声で流す

## 使い道

データから「今何が起きているか」を言葉にする技術の実践例。運用アラートの要約などにも応用できる

## 確かめ方（評価）

実況に出てきた順位やタイム差が、その時点のデータと一致するかを自動で照合する。大事な出来事を取りこぼしていないかも数える

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

「出来事の検出」はコードで行い、AIは実況の文章づくりだけを担当する。音声はVOICEVOXなどで合成し、前日のデータを使い回す。チーム無線の音声は使わない
