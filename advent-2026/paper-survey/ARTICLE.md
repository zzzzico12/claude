## 今日作ったもの

調べたいテーマを日本語で入れると、重要な論文を20本選び、**無料で読めるリンク**と**日本語の解説**をまとめた「サーベイ」を作るWebアプリです。

（スクリーンショットかGIF）

デモ：https://advent26-paper-survey.vercel.app （1日10回まで。一度調べたテーマは何度でも見られます）

- 「全体の見取り図」「流れごとの解説」「まず読むとよい論文」「論文ごとの要約」を書く
- 解説のすべての文に、根拠の論文番号 `[3]` が付き、クリックすると表の論文に飛ぶ
- 引用数・年・無料リンクは、AIではなくデータから表に出す

新しい技術を調べるときの「最初の1時間」を短くするのが目的です。

## 使ったオープンデータ

| データ | 用途 | 提供元・ライセンス |
| --- | --- | --- |
| [OpenAlex](https://openalex.org/) | 論文の検索、引用数、抄録、評価用の参考文献 | OurResearch・CC0 |
| [Unpaywall](https://unpaywall.org/) | 雑誌論文の無料で読めるリンク | OurResearch |
| [arXiv](https://arxiv.org/) | プレプリントへのリンク | Cornell University |

OpenAlex は2億件以上の論文を持つ、無料の学術データベースです。2026年2月から無料のAPIキーが必須になりました。

## 仕組み

```
テーマ（日本語）
  │ ① Claude：英語の検索語を2〜4個に言い換える
  ▼
OpenAlex を関連度順に検索（検索語ごとに上位100件）
  │ ② コード：重複をまとめ、点数で並べ直して上位20本
  ▼
無料リンク：arXiv → OpenAlex の oa_url → Unpaywall
  │ ③ Claude：抄録だけを根拠に、日本語のサーベイを書く（ストリーミング）
  ▼
④ コード：根拠の番号と数字を照合 → 画面
```

AIに任せたのは①と③だけです。**どの論文を選ぶか（②）と、数字の確認（④）はコードで行いました。**

- 構成：Vite + TypeScript の画面と、Vercel Functions の API 1本。OpenAlex のキーと Unpaywall に送るメールアドレスは、サーバー側だけで使います
- AI：Claude Sonnet 5.5（1回およそ10円）

## 工夫したところ

### 1. 引用数で並べない

最初に「retrieval augmented generation」を**引用数の多い順**で検索したら、上位は GPT-3、GPT-4、SciPy でした。どれも有名な論文ですが、RAG のサーベイの1本目に来るものではありません。

そこで、OpenAlex の**関連度**で候補を集めてから、次の3つの点数で並べ直しました。

- 関連度：検索での順位。複数の検索語で見つかった論文は少し上げる
- **1年あたりの引用数**（対数）：古い論文ほど引用が増えるので、出てからの年数で割る
- 新しさ：期間の中で新しいほど高い（重みは小さめ）

### 2. 根拠の番号と数字を、コードで照合する

AIには「抄録に書かれていないことは書かない」「文末に根拠の番号を付ける」「引用数や年は書かない」と指示しました。そのうえで、書かれた文章をコードで照合しています。

- `[n]` の番号が、実在する20本のどれかを指しているか
- 一度も使われなかった論文はないか
- 本文の数字が、元データ（抄録・年・引用数）のどれかと一致するか

数字の照合は、25日間すべてで使えるよう共通部品にしました。「約1.2万」のような丸めた書き方や、「45 million」を「4,500万」と書き直した場合も一致とみなします。

### 3. 公開デモの料金を抑える

1日の上限は全体で10回にしました（1回約10円なので、最大でも約100円）。同じテーマの結果は30日キャッシュして、2回目からはClaudeを呼びません。

## ハマったところ

- **抄録の代わりに書誌情報が入っている論文**：「著者名＋会議名」だけの抄録がありました。AI は正直に「内容を確認できない」と書きましたが、それでは要約になりません。300文字未満の抄録は候補から外しました
- **年が新しすぎる論文**：2024年1月に arXiv に出た論文の年が、OpenAlex では2026年になっていました（雑誌版の年）。arXiv の番号 `2401.xxxxx` から年を出し、早いほうを使うようにしました
- **Unpaywall は arXiv の論文を知らない**：Unpaywall が対象にするのは Crossref の DOI だけで、arXiv の DOI（`10.48550/...`）は 404 になります。arXiv の論文は arXiv のリンクを直接使います
- **数字の照合の誤検出**：英語の「45 million」を AI が正しく「4,500万」に直したのに、照合する側が「million」を読めずに警告を出しました。照合する側を直しました

## どれくらいうまくいったか

**既存のサーベイ論文5本の参考文献を正解**として、このアプリが選んだ20本のうち何本が参考文献に入っていたかを測りました。

- 対象：RAG、LLMエージェント、拡散モデル、Vision Transformer、RLHF の、よく引用されているサーベイ
- 公平にするため、検索はサーベイの arXiv 第1版より前の論文に限りました
- テーマはサーベイのタイトルではなく、「拡散モデル」のような短い日本語にしました

| 方式 | 上位20本のうち参考文献に入っていた割合 |
| --- | --- |
| ① OpenAlex を関連度順に検索しただけ | 38.0% |
| ② 候補を引用数の多い順に並べただけ | 40.0% |
| **③ このアプリ** | **50.0%** |

5本すべてで、③がいちばん良い結果でした。重みは最初に決めた値のままで、評価に合わせた調整はしていません。

限界もあります。

- サーベイの参考文献は150〜350本あるので、20本で拾える割合（再現率）は5%前後です
- 参考文献に入っていない論文が、関係のない論文とは限りません
- 検索語は Claude が作るので、実行するたびに結果が少し変わります
