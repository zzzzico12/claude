# Day 17（12/17 木）風船を飛ばしたらどこへ行く？

- **アプリ名（フォルダ名）**：`balloon-flight-simulator`
- **ジャンル**：空
- **完成形**：Webアプリ
- **組み合わせるデータ**：Open-Meteo（高さごとの風）× OpenStreetMap
- **AI・技術の見どころ**：軌跡シミュレーション

## 作るもの

今いる場所から風船を放したら、高さごとの風に乗ってどこをどう飛んで、どこに落ちるかを計算し、地図上でアニメーションにする

## 使い道

気象データを使った軌跡シミュレーションの実践例。「もし今日放したら」を何度も試せる

## 確かめ方（評価）

公開されている観測用の気球（ラジオゾンデ）の実際の飛行記録と、同じ条件で計算した軌跡を比べる

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

風船の上昇速度と破裂する高さは決め打ちにし、風はOpen-Meteoの高さごとの予報を使う
