# Day 11（12/11 金）頭上の飛行機ガイド

- **アプリ名（フォルダ名）**：`plane-overhead-guide`
- **ジャンル**：空
- **完成形**：スマホ向けWebアプリ（PWA）
- **組み合わせるデータ**：OpenSky × OurAirports × 行き先の天気
- **AI・技術の見どころ**：位置からの特定＋解説

## 作るもの

スマホで開くと、今頭上を飛んでいる飛行機の機種、出発地、行き先、到着地の天気を教える

## 使い道

空を見上げたときの「あれはどこ行き？」に答える

## 確かめ方（評価）

空港の近くで、表示した便と実際に見えた飛行機が一致した割合を数える

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

OpenSkyは2026年3月からOAuth2の認証が必要。方位センサーは使わず、「半径10km以内で一番低く飛んでいる飛行機」から並べる。APIキーはサーバー側に置く

## 必要な環境変数

- `OPENSKY_CLIENT_ID`
- `OPENSKY_CLIENT_SECRET`
