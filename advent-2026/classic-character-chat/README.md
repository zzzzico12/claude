# Day 18（12/18 金）名作の登場人物と話す

- **アプリ名（フォルダ名）**：`classic-character-chat`
- **ジャンル**：文学
- **完成形**：Webアプリ
- **組み合わせるデータ**：Project Gutenberg × Wikidata
- **AI・技術の見どころ**：RAG・ロールプレイ

## 作るもの

著作権の切れた名作の本文だけを根拠に、登場人物として答えるチャット。答えには根拠となる本文の箇所を添える

## 使い道

「資料にないことを言わないAI」を作る技術の練習。社内文書のRAGにそのまま応用できる

## 確かめ方（評価）

本文に答えがある質問とない質問を各20問用意し、正しく答える率と、「わからない」と言える率を測る

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

作品を1本に絞り、本文の分割とベクトル化は前日までに済ませる
