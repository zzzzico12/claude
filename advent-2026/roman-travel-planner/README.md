# Day 22（12/22 火）古代ローマの旅行計画

- **アプリ名（フォルダ名）**：`roman-travel-planner`
- **ジャンル**：歴史
- **完成形**：Webアプリ
- **組み合わせるデータ**：ローマ帝国の道路網（Itiner-e）× Pleiades
- **AI・技術の見どころ**：経路探索

## 作るもの

「ローマからロンドンまで」のように入れると、ローマ帝国の道路網で経路を探し、徒歩・馬車・船で何日かかるかを、途中の街の解説つきで出す。古代の乗り換え案内

## 使い道

歴史のスケールを体感する。グラフの経路探索の実践例

## 確かめ方（評価）

古代の旅程記録（アントニヌスの旅程表など）や、スタンフォード大学のORBISの計算結果と、日数を比べる

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

道路網は公開データ（Itiner-e）をそのままグラフにし、移動の速さは文献の値を使う。海路は主要な航路だけ手で足す
