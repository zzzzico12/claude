# Day 16（12/16 水）あの山の名前は？

- **アプリ名（フォルダ名）**：`mountain-name-finder`
- **ジャンル**：景色
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：Copernicus DEM × OpenStreetMap
- **AI・技術の見どころ**：見通し計算＋写真と稜線の照合

## 作るもの

今いる場所から見える360度の山並みを標高データから計算して描き、山の名前を付ける。山の写真をアップロードすると、計算した稜線と写真の稜線を照らし合わせて、写っている山に名前を付ける

## 使い道

山や旅先で「あの山は何？」に答える。地球の丸みを考えた見通し計算の実践例

## 確かめ方（評価）

山名がわかっている写真で、正しく名前を付けられた割合を測る

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

方位センサーは使わず、パノラマを土台にする。写真合わせは「稜線の形の一致」から始め、対象地域の標高データを事前に切り出しておく
