# 名画テーマ（Masterpiece Theme）

パブリックドメインの名画 17 点の色から作った、VS Code の配色テーマです。

- **絵の色をそのまま使う**：絵から代表色を取り出し、どの色を背景・キーワード・コメントなどに使うかを AI（Claude）が絵を見て決めました
- **読みやすさを保証**：すべての文字の色は、背景とのコントラスト比 4.5:1（WCAG AA）以上に自動で調整しています
- **天気と時間で切り替わる**（オンにした場合）：雨の日はカイユボットの「パリの通り、雨の日」、夜はホイッスラーの「夜想曲」のように、いまの天気と時間帯に合う絵のテーマに切り替わります
- **絵をいつも横に**：エクスプローラーの下の「名画」パネルに、いまのテーマの絵と、そこから取った色の帯を表示します（ドラッグで右側のサイドバーにも移せます）
- **絵の解説つき**：パネルの絵かステータスバーの絵の名前を押すと、作品の画像と解説、配色の意図が表示されます

## 使い方

1. コマンドパレット（`Ctrl+Shift+P` / `Cmd+Shift+P`）で **「名画テーマ: 絵を選ぶ」** を実行し、好きな絵を選ぶ（または「基本設定: 配色テーマ」から「名画: …」を選ぶ）
2. 天気と時間で切り替えたいときは **「名画テーマ: 天気と時間で自動で切り替える」**。設定 `masterpieceTheme.latitude` / `longitude` に住んでいる場所を入れる（既定は東京）
3. エクスプローラーの下の **「名画」** パネルに、いまの絵が表示されます。閉じてしまったら **「名画テーマ: 絵をサイドバーに表示」**
4. 絵をクリック（または **「名画テーマ: いまの絵について」**）で、解説を表示

エディタの背景に絵を敷く公式の方法は VS Code にないので、絵は横のパネルに表示しています（VS Code 本体のファイルは書き換えません）。

| コマンド | 内容 |
| --- | --- |
| 名画テーマ: 絵を選ぶ | 一覧から絵を選んでテーマにする |
| 名画テーマ: いまの絵について | 絵の画像・解説・配色を表示 |
| 名画テーマ: 絵をサイドバーに表示 | 「名画」パネルを開く |
| 名画テーマ: 天気と時間で自動で切り替える | 自動の切り替えをオンにして、すぐ切り替える |
| 名画テーマ: いまの天気で選び直す | 天気を取り直して切り替える |
| 名画テーマ: 自動の切り替えを止める | 自動の切り替えをオフにする |

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| `masterpieceTheme.autoSwitch` | `false` | 天気と時間帯で自動で切り替える |
| `masterpieceTheme.latitude` / `longitude` | 東京 | 天気を調べる場所 |
| `masterpieceTheme.intervalMinutes` | `60` | 天気を確かめる間隔（分、15以上） |

天気と時間帯の決め方：嵐（雷雨・強風）→ 雪 → 雨 → 朝（日の出前後）→ 夕方（日の入り前後）→ 夜 → くもり → 晴れ の順に当てはめ、その雰囲気の絵を選びます（合う絵が複数あれば日替わり）。

## プライバシー

- 自動の切り替えをオンにしたときだけ、設定した緯度・経度を [Open-Meteo](https://open-meteo.com/) に送って天気を取得します。それ以外の通信はしません（「名画」パネルと解説の画面は、シカゴ美術館のサーバーから絵の画像を読み込みます）
- AI は拡張機能の中では動きません（配色と解説は事前に作ってあります）
