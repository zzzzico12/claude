# Day 14（12/14 月）似ている作品の横断検索

- **アプリ名（フォルダ名）**：`similar-artwork-search`
- **ジャンル**：名画
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：複数の美術館の画像 × Wikidata
- **AI・技術の見どころ**：ベクトル検索

## 作るもの

1枚の絵を選ぶと、世界の美術館から構図や雰囲気の似た作品を探し、どこが似ているかをAIが説明する

## 使い道

画像のベクトル検索を作るときの実践例。自社の画像検索に応用できる

## 確かめ方（評価）

上位10件に、同じ作家や同じ派の作品がどれだけ入るかを、Wikidataの情報で採点する

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

画像のベクトル化は公開済みのモデルで事前に済ませ、数千枚に絞る。12/13の名画のデータも使い回す
