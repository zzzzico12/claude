# Day 23（12/23 水）F1のゴースト比較

- **アプリ名（フォルダ名）**：`f1-ghost-lap`
- **ジャンル**：F1
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：OpenF1のテレメトリ × コース図
- **AI・技術の見どころ**：テレメトリ分析＋解説

## 作るもの

2人のドライバーの最速ラップをコース図の上で重ねて再生し、「ターン9でブレーキを踏むのが10m遅い」のように、どこでタイム差がついたかをAIが解説する

## 使い道

F1をデータで楽しむ。時系列データを位置でそろえて比べる技術の実践例

## 確かめ方（評価）

AIが指摘した区間のタイム差を、テレメトリから計算した値と自動で照合する

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

OpenF1は非公式データで、細かいテレメトリは2023年以降が中心。対象は有名な予選の1周に絞る。F1のロゴや映像は使わない
