# Day 05（12/5 土）衛星画像で森の変化を検知

- **アプリ名（フォルダ名）**：`forest-change-detector`
- **ジャンル**：宇宙
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：Sentinel-2 × Global Forest Watch × OpenStreetMap
- **AI・技術の見どころ**：植生指数＋画像の説明

## 作るもの

地域を選ぶと、2つの時期の衛星画像から植物の量の変化を計算し、変化した場所とその理由の候補をAIが説明する

## 使い道

環境調査や、地理空間データを扱う開発の入門

## 確かめ方（評価）

Global Forest Watchの森林減少データを正解として、検知した場所がどれだけ重なるかを測る

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

機械学習は使わず、植生指数（NDVI）の引き算で検知する。対象は1か所に絞り、画像は事前にダウンロードしておく

## 必要な環境変数

- `COPERNICUS_CLIENT_ID`
- `COPERNICUS_CLIENT_SECRET`
- `GFW_API_KEY`
