# Day 25（12/25 金）AIサンタの配達ルート

- **アプリ名（フォルダ名）**：`santa-route-optimizer`
- **ジャンル**：最終日
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：GHSL（人口分布）× タイムゾーン × 世界の天気
- **AI・技術の見どころ**：経路最適化＋3Dの地球儀

## 作るもの

世界の人口分布、タイムゾーンと夜の時間、世界の天気から、一晩で世界中の子どもに配るための最適なルートを計算し、3Dの地球儀でアニメーションにする。各地に着いたときの天気や現地の時刻をAIが実況する

## 使い道

クリスマスの締めくくり。配送ルートなどの巡回問題を、時間の制約つきで解く実践例

## 確かめ方（評価）

「各地に夜のうちに着けたか」を全地点で検査し、単純な方法（東から西へ順に回る）と総移動距離を比べる

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

人口分布は大きなマス目にまとめて地点数を数千に減らし、最適化は公開のソルバー（OR-Toolsなど）を使う。12/6の地球儀の描画を使い回す
