# Day 15（12/15 火）港の船ガイド

- **アプリ名（フォルダ名）**：`harbor-ship-guide`
- **ジャンル**：海
- **完成形**：スマホ向けWebアプリ（PWA）
- **組み合わせるデータ**：北欧の船舶位置データ（AIS）× 世界の港のデータ
- **AI・技術の見どころ**：位置からの特定＋解説

## 作るもの

港や海岸で開くと、見えている船の名前、種類、どこから来てどこへ向かうかを教える。「頭上の飛行機ガイド」の海版

## 使い道

海の物流を身近に感じる。リアルタイムの位置データを扱う実践例

## 確かめ方（評価）

港の公式の入港予定と、表示した船の行き先が一致するかを確かめる

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

無料で公開されている北欧の船舶位置データを使い、対象の港を1つに絞る。12/11の画面の部品を使い回す

## 必要な環境変数

- `AIS_API_KEY`
