# Day 21（12/21 月）ダーウィンの航海をたどる

- **アプリ名（フォルダ名）**：`darwin-voyage-map`
- **ジャンル**：博物学
- **完成形**：Webアプリ＋Pythonのデータ処理
- **組み合わせるデータ**：『ビーグル号航海記』× GBIF・ロンドン自然史博物館の標本
- **AI・技術の見どころ**：本文からの地名抽出＋地図

## 作るもの

『ビーグル号航海記』の本文から地名を抜き出して航路を地図に描き、各地で書いた文章と、そこで実際に集めた標本の記録を並べて見せる

## 使い道

本文から地名を取り出して地図にする技術の実践例。歴史と科学を一緒に楽しめる

## 確かめ方（評価）

抜き出した地名の位置を、既知の航路と比べて正しい割合を測る

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

古い地名は今の地名と違うことがあるので、AIに今の地名への対応を付けさせ、位置はGeoNamesで確かめる。標本はGBIFで「採集者：Darwin」の記録を使う
