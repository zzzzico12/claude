# Day 10（12/10 木）ボイジャーは今どこ？

- **アプリ名（フォルダ名）**：`where-is-voyager`
- **ジャンル**：宇宙
- **完成形**：Webアプリ
- **組み合わせるデータ**：NASA JPL Horizons × 探査機のミッション情報
- **AI・技術の見どころ**：3Dでの旅の再生

## 作るもの

ボイジャーやはやぶさ2などの探査機が、打ち上げから今までどう旅してきたかを3Dで再生し、今いる場所と、地球まで電波が届く時間をAIが解説する

## 使い道

宇宙探査のスケールを実感する。天体の位置計算APIの使い方の実践例

## 確かめ方（評価）

NASAが公開しているボイジャーの現在の距離と、計算した値が一致するか

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

位置はJPL Horizonsから事前に取得しておき、探査機は3〜5機に絞る。地球儀・3D描画は12/6の部品を使う
