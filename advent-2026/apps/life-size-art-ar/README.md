# Day 19（12/19 土）名画を実物大で部屋に飾る

- **アプリ名（フォルダ名）**：`life-size-art-ar`
- **ジャンル**：名画
- **完成形**：スマホ向けWebアプリ（PWA）
- **組み合わせるデータ**：美術館の画像と作品の実寸データ
- **AI・技術の見どころ**：WebのAR

## 作るもの

美術館のデータにある作品の実寸を使って、スマホのARで名画を自分の部屋に実物大で飾る。「モナ・リザは意外と小さい」がその場でわかる

## 使い道

美術館に行く前の予習や、部屋に飾る絵のサイズ確認。WebのARの実践例

## 確かめ方（評価）

メジャーで壁に印を付け、表示された絵の大きさと実寸のずれを測る

評価のスクリプトと結果は `eval/` に置く。

## 1日で作る工夫・注意

美術館の寸法は文章で書かれているので、数値の抽出をAIに任せてコードで検算する。ARはWebXR、iPhone向けにはUSDZ（Quick Look）も用意する
