# Voice Painter

マイクに向かって声を出すだけで絵が描けるアプリです。音程・音量・音色がそれぞれ色・太さ・方向に対応し、声の変化がそのまま筆跡になります。

## 特徴

- 声だけでキャンバスに描画
- 音程 → 色相（低音=赤、高音=紫）
- 音量 → ブラシの太さ
- 音程×音色 → 描画の方向
- リアルタイムパラメータ表示
- ダークモード対応

## 技術スタック

- HTML5
- Web Audio API
- Canvas API
- JavaScript
- CSS3

## 使い方

1. [voice-painter.html](voice-painter.html)をブラウザで開く
2. マイクへのアクセスを許可
3. マイクに向かって声を出す
4. 音程・音量・音色の変化に応じて絵が描かれる
5. 声を止めると描画も止まる

## パラメータ対応

| 声の特徴 | 描画への影響 |
|----------|-------------|
| 音程（高低） | 色相（低音=赤 / 高音=紫） |
| 音量 | ブラシの太さ |
| 音程×音色 | 描画方向（高音=上 / 低音=下 / 音色=左右） |

## ブラウザ要件

- マイクアクセス可能なブラウザ
- Web Audio API対応
- 推奨：Chrome、Firefox（最新版）
