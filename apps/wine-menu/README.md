# WINE LIST AI

ワインメニューの写真をAIで解析し、データベース化できるPWAアプリです。Claude APIを使用してメニュー画像から情報を自動抽出します。

## 特徴

- ワインメニュー画像のAI解析
- 自動情報抽出（名前、産地、味わい、価格など）
- ワインの種類別フィルタリング（赤・白・スパークリング）
- 詳細情報の表示
- おすすめワインのマーキング機能
- 美しいカードUIデザイン
- PWA対応（ホーム画面に追加・オフライン利用可能）

## 技術スタック

- Vanilla HTML / CSS / JavaScript（スタンドアロン）
- React 18 (UMD CDN) + Babel Standalone
- Tailwind CSS (Play CDN)
- Claude AI API (画像認識・テキスト抽出)
- Service Worker (キャッシュ・PWA)

## 使い方

1. [wine-menu.html](wine-menu.html) をブラウザで開く（またはホーム画面に追加）
2. Claude API キーを入力して保存
3. ワインメニューの写真をアップロード
4. AIが自動的にメニューを解析
5. 抽出されたワイン情報を閲覧・管理

## 抽出される情報

各ワインについて以下の情報が自動抽出されます：

- **name**: ワインの日本語名
- **nameEn**: ワインの英語名
- **origin**: 産地（国と地域）
- **color**: ワインの色（赤・白・スパークリング）
- **taste**: 味わい（辛口・甘口など）
- **body**: ボディ（フルボディ・ミディアム・ライトなど）
- **description**: ワインの特徴や説明
- **price**: 価格

## 主な機能

### 画像アップロード
- カメラ撮影またはファイル選択
- ワインメニューの写真をアップロード

### AI解析
- Claude APIによる高精度な画像認識
- 複数のワイン情報を一度に抽出

### フィルタリング
- 全て表示
- 赤ワインのみ
- 白ワインのみ
- スパークリングのみ

### 詳細表示
- ワインカードをクリックで詳細情報表示
- 産地、味わい、ボディなどの詳細

## API設定

アプリ内のAPIキー入力欄にClaude API キーを入力してください。キーはブラウザのlocalStorageに保存されます。

## ユースケース

- レストランでのワインメニューのデジタル化
- ワインリストの整理・管理
- ワインの情報収集
- おすすめワインの記録
