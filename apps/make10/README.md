# Make 10

4つの数字を四則演算で組み合わせて「10」を作るパズルゲームです。

## 特徴

- ランダムに配られた4つの数字（0〜9）で10を目指す
- 四則演算（＋−×÷）を自由に組み合わせ
- 数字は左から順に使う制約あり
- ヒント機能・プレイ統計の記録

## 技術スタック

- HTML5
- JavaScript
- CSS3

## 使い方

1. [make10.html](make10.html)をブラウザで開く
2. 表示された4つの数字カードを左から順にクリック
3. 数字の間に演算子（＋−×÷）を選んで式を組み立てる
4. 計算結果が10になれば正解
5. わからない場合は**ヒント**ボタンで解答例を確認

## ルール

- 4つの数字すべてを使う
- 数字は表示された順（左から右）に使うこと
- 四則演算と括弧を使って組み合わせ可能
- 答えが10になる式を作れば正解

## 統計

- 正解数・試行回数・正解率をリアルタイムで記録
