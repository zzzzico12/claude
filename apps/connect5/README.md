# Connect 5

五目並べ（ゴモク）のAI対戦ゲームです。縦・横・斜めのいずれかに5つの石を連続して並べた方が勝ちです。

## 特徴

- プレイヤー（青）vs AI（赤）の1対1対戦
- SVGベースのボード描画
- リアルタイムAI応手

## 技術スタック

- HTML5
- SVG
- JavaScript（ミニマックスAI）

## 使い方

1. [connect5.html](connect5.html)をブラウザで開く
2. ボード上をクリックして石を置く
3. 縦・横・斜めに5つ連続で並べると勝ち
4. **New game** ボタンで再スタート

## ルール

- 先手：プレイヤー（青石）
- 後手：AI（赤石）
- 縦・横・斜めのいずれかに5つ連続で並べた方が勝ち
- ボードが埋まると引き分け
