# ヒット＆ブロー

プレイヤーとAIが互いに隠した3桁の数字を当て合う推理ゲームです。

## 特徴

- プレイヤー vs AI の相互推理バトル
- ヒット・ブローの手がかりをもとに絞り込む
- 全試行履歴の表示

## 技術スタック

- HTML5
- JavaScript
- CSS3

## 使い方

1. [hit_and_blow.html](hit_and_blow.html)をブラウザで開く
2. 0〜9の重複なし3桁の数字を設定する（自分の秘密の数字）
3. AIの数字を推理して入力する
4. ヒント（Hit / Blow）をもとに絞り込む
5. 3ヒットで勝ち

## ルール

| 結果 | 意味 |
|------|------|
| **Hit** | 数字も位置も正解 |
| **Blow** | 数字は正解だが位置が違う |

- 使用する数字：0〜9（重複なし）
- 桁数：3桁
- 3ヒットで勝利
