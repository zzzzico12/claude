# Mood Pixel Art

今の気持ちをテキストで入力すると、AIがその気分に合ったピクセルアートを生成するアプリです。

## 特徴

- 気分をテキストで自由入力（最大60文字）
- Claude APIがピクセルアートを生成
- 生成履歴の表示と振り返り
- シンプルでミニマルなUI

## 技術スタック

- HTML5
- JavaScript
- Claude API（Anthropic）

## 使い方

1. [mood-pixel-art.html](mood-pixel-art.html)をブラウザで開く
2. Anthropic APIキーを入力
3. 今の気分を自由にテキスト入力
4. **生成**ボタンをクリック
5. AIが気分に合ったピクセルアートを生成

## 必要なもの

- Anthropic APIキー（[console.anthropic.com](https://console.anthropic.com)で取得）

## プライバシー

- APIキーはブラウザ内のみで使用
- 入力テキストはAnthropicのAPIに送信される
