# Station Quest

新宿駅を3Dで再現した駅ナビゲーションゲームです。指定された出口を目指して構内を探索します。

## 特徴

- 新宿駅B1F・1Fを実寸スケールで3D再現
- Three.jsによるリアルタイム3Dレンダリング
- WASD操作＋マウス視点のFPS風移動
- 階段エリアでのフロア自動移動
- ゴール到達タイムの計測

## 技術スタック

- HTML5
- Three.js
- JavaScript
- CSS3

## 使い方

1. [index.html](index.html)をブラウザで開く
2. スタート駅を選択
3. 表示されたお題の出口・乗り換え口を目指して移動
4. ゴールに到達するとクリアタイムが表示される

## 操作方法

| 操作 | 内容 |
|------|------|
| WASD | 移動 |
| マウスドラッグ | 視点回転 |
| Shift | 走る |
| 階段エリア | 自動でフロア移動 |

## マップ

- **B1F**：北コンコース・東西メインコンコース
- **1F**：各ホーム・改札
